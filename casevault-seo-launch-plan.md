# Casevault SEO launch plan

## Search positioning

The site is structured around high-intent queries instead of repeating a single
keyword across every page.

| Search intent | Primary page | Core query cluster |
| --- | --- | --- |
| Category | `/` | immigration case management software; immigration practice management software |
| Product evaluation | `/features/` | immigration case tracking; immigration workflow software |
| Case operations | `/case-management/` | visa case management; immigration matter tracking |
| Documents | `/document-management/` | immigration document management software; visa document tracking |
| Client experience | `/client-portal/` | immigration client portal; case update portal |
| Workflow | `/how-it-works/` | immigration workflow software; client intake case management |
| Commercial | `/pricing/` | immigration software pricing; case management software cost |
| Trust | `/security/` | secure immigration case management; immigration data security |
| Persona | `/solutions/solo-consultants/` | immigration consultant software; solo immigration practice |
| Persona | `/solutions/immigration-law-firms/` | immigration law firm software; immigration legal case management |
| Geographic operations | `/solutions/multi-country-practices/` | multi-country immigration case management; global mobility case software |

These terms are used naturally in titles, headings, descriptions, body copy,
internal links, and page topics. A keywords meta tag is included for stakeholder
reference, but Google does not use it for ranking.

## Structured data

- `Organization` and `WebSite` on every indexable page.
- `WebApplication` with current public plan offers on the homepage.
- `BreadcrumbList` on interior pages.
- `FAQPage` on the FAQ page.
- `AboutPage` and `ContactPage` on their respective pages.

No aggregate rating or review markup is included because the site does not yet
provide a verifiable rating source. Structured data must reflect visible,
truthful content.

## Launch checklist

1. Connect `casvault.com` to the Cloudflare Pages project only after the preview
   deployment is accepted.
2. Verify both the apex domain and preferred canonical version resolve
   consistently over HTTPS.
3. Add the domain property in Google Search Console and submit
   `https://casvault.com/sitemap.xml`.
4. Request indexing for the homepage, pricing, features, case management,
   document management, and client portal pages.
5. Run Google Rich Results Test and Schema Markup Validator on production URLs.
6. Connect privacy-respecting analytics and define demo-request conversions.
7. Publish proof-led articles answering real immigration-practice operations
   questions; link them back to the relevant product pages.
8. Build legitimate citations and partnerships in immigration consulting, legal
   operations, and global mobility communities. Do not buy bulk links.
9. Review Search Console queries monthly and improve pages with impressions but
   weak click-through rates.

## First content opportunities

- Immigration case management software: evaluation checklist
- How to organize visa documents without client email chains
- A client intake workflow for immigration consultants
- How immigration practices can reduce case-status update calls
- Immigration case management software for multi-country teams
- Case deadline management: a practical operating system

No technical implementation can guarantee rankings. The launch establishes a
strong crawlable foundation; authority, useful content, product proof, links,
engagement, and continued iteration determine performance over time.
